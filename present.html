.claude/フォルダ構成テンプレート

CLAUDE.md・SKILL.md・サブエージェント・settings.jsonの4点セット＋フォルダ全体の見取り図です。

1. プロジェクトルートの CLAUDE.md
保存先: プロジェクトのルート直下 ./CLAUDE.md
# <プロジェクト名>

## このプロジェクトについて
<何を作っているか、1〜2文で>

## よく使うコマンド
- ビルド: `<コマンド>`
- テスト: `<コマンド>`
- Lint: `<コマンド>`

## コーディング規約
- <インデント・命名規則など、具体的に書けるものを箇条書きで>

## ディレクトリ構成
- `<フォルダ名>` — <何が入っているか>

## 注意事項
- <Claude Codeに毎回説明し直すのが面倒な、プロジェクト固有の前提知識>
2. 個人用スキルのひな形 SKILL.md
保存先: ~/.claude/skills/<スキル名>/SKILL.md（プロジェクト固有なら .claude/skills/<スキル名>/SKILL.md）
---
description: <このスキルが何をするか、いつ使うかを具体的に。トリガーになる言葉を含める>
---

# <スキル名>

<Claudeへの具体的な指示。手順・チェック項目・出力フォーマットまで書く>

1. <手順1>
2. <手順2>
3. <手順3>

## 注意点
- <このスキルを使う上で気をつけてほしいこと>
3. サブエージェントのひな形
保存先: .claude/agents/<エージェント名>.md（個人用は ~/.claude/agents/）
---
name: <エージェント名>
description: <どんなタスクのときにこのエージェントへ委譲すべきか>
tools: Read, Grep, Glob
model: sonnet
---

あなたは<役割>を専門とするエージェントです。

<このエージェントが従うべき行動指針・出力フォーマットを具体的に>

- <指針1>
- <指針2>
4. settings.jsonの基本テンプレート
保存先: .claude/settings.json（個人だけの設定は .claude/settings.local.json）
{
  "permissions": {
    "allow": [
      "Bash(git status)",
      "Bash(git diff *)",
      "Bash(npm test)"
    ],
    "deny": [
      "Bash(rm -rf *)"
    ]
  },
  "env": {
    "EXAMPLE_ENV_VAR": "value"
  }
}
5. フォルダ全体の見取り図
1〜4をどこに配置するかの全体像です。
my-project/
├── CLAUDE.md                          # プロジェクト共通の指示（1と同じ内容）
├── .claude/
│   ├── settings.json                  # チーム共有設定（4と同じ内容）
│   ├── settings.local.json            # 個人設定（.gitignore推奨）
│   ├── agents/
│   │   └── <エージェント名>.md         # サブエージェント定義（3と同じ内容）
│   ├── skills/
│   │   └── <スキル名>/
│   │       └── SKILL.md               # プロジェクト固有スキル（2と同じ内容）
│   └── rules/
│       └── <トピック名>.md             # 大きくなったCLAUDE.mdを分割するとき用
受け取り方：各ページを開き、使いたい項目の「📋 コピー」を押すか、上部/各カードの「⬇」でファイルごとに保存できます。Skills100選・プロンプト集は、それぞれのページ上部の「⬇ 全件ダウンロード」でまとめて保存することもできます。
