# 🎁 .claude/フォルダ構成テンプレート

Claude Codeのプロジェクトでよく使う設定ファイル一式を、そのままコピーして使えるひな形としてまとめました。CLAUDE.md・SKILL.md・サブエージェント・settings.jsonの4点セットです。

**使い方**: 各ブロックをそのままファイルとして保存し、プロジェクトの`.claude/`フォルダ以下に配置してください。中身の`< >`で囲んだ部分は自分のプロジェクトに合わせて書き換えます。

---

## 1. プロジェクトルートの `CLAUDE.md`

保存先: プロジェクトのルート直下 `./CLAUDE.md`

```text
# <プロジェクト名>

## このプロジェクトについて
<何を作っているか、1〜2文で>

## よく使うコマンド
- ビルド: `<コマンド>`
- テスト: `<コマンド>`
- Lint: `<コマンド>`

## コーディング規約
- <インデント・命名規則など、具体的に書けるものを箇条書きで>

## ディレクトリ構成
- `<フォルダ名>` — <何が入っているか>

## 注意事項
- <Claude Codeに毎回説明し直すのが面倒な、プロジェクト固有の前提知識>
```

## 2. 個人用スキルのひな形 `~/.claude/skills/<スキル名>/SKILL.md`

保存先: 個人用は`~/.claude/skills/<スキル名>/SKILL.md`、プロジェクト固有にしたい場合は`.claude/skills/<スキル名>/SKILL.md`

```text
---
description: <このスキルが何をするか、いつ使うかを具体的に。Claudeがこれを見て自動発火するかどうかを判断するので、トリガーになる言葉を含める>
---

# <スキル名>

<Claudeへの具体的な指示。手順・チェック項目・出力フォーマットまで書く>

1. <手順1>
2. <手順2>
3. <手順3>

## 注意点
- <このスキルを使う上で気をつけてほしいこと>
```

補足: 手動でしか呼び出したくない場合は、フロントマターに`disable-model-invocation: true`を追加すると、`/スキル名`で明示的に呼んだときだけ動くようになります。特定のツールだけを事前承認したい場合は`allowed-tools: Bash(git *) Read Write`のように追加できます。

## 3. サブエージェントのひな形 `.claude/agents/<エージェント名>.md`

保存先: プロジェクト用は`.claude/agents/<エージェント名>.md`、個人用は`~/.claude/agents/<エージェント名>.md`

```text
---
name: <エージェント名>
description: <どんなタスクのときにこのエージェントへ委譲すべきか。Claudeが判断材料にする説明文>
tools: Read, Grep, Glob
model: sonnet
---

あなたは<役割>を専門とするエージェントです。

<このエージェントが従うべき行動指針・出力フォーマットを具体的に>

- <指針1>
- <指針2>
```

補足: `tools`を絞ることで、そのエージェントが読み取り専用になるか、書き込みまでできるかを制御できます。`model`を指定しない場合はメインの会話のモデルを引き継ぎます。

## 4. `settings.json`の基本テンプレート

保存先: プロジェクト共有設定は`.claude/settings.json`、個人だけの設定は`.claude/settings.local.json`（`.gitignore`推奨）

```text
{
  "permissions": {
    "allow": [
      "Bash(git status)",
      "Bash(git diff *)",
      "Bash(npm test)"
    ],
    "deny": [
      "Bash(rm -rf *)"
    ]
  },
  "env": {
    "EXAMPLE_ENV_VAR": "value"
  }
}
```

補足: `permissions.allow`に入れたコマンドは確認なしで実行されるようになります。危険な操作は`permissions.deny`に明示しておくと安全です。実行モードの既定値を変えたい場合は`"permissions": {"defaultMode": "plan"}`のように`defaultMode`を追加すると、セッション開始時からプランモードなどで始められます。

## 5. フォルダ全体の見取り図

```text
my-project/
├── CLAUDE.md                          # プロジェクト共通の指示（1と同じ内容）
├── .claude/
│   ├── settings.json                  # チーム共有設定（4と同じ内容）
│   ├── settings.local.json            # 個人設定（.gitignore推奨）
│   ├── agents/
│   │   └── <エージェント名>.md         # サブエージェント定義（3と同じ内容）
│   ├── skills/
│   │   └── <スキル名>/
│   │       └── SKILL.md               # プロジェクト固有スキル（2と同じ内容）
│   └── rules/
│       └── <トピック名>.md             # 大きくなったCLAUDE.mdを分割するとき用
```

個人用スキル・エージェントは`~/.claude/skills/`・`~/.claude/agents/`に置くと、すべてのプロジェクトで共通して使えるようになります。プロジェクト固有にしたいものだけ、上記のように`.claude/`以下に置いてください。
