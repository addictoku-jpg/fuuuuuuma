1

そもそも「スキル」って何なのか

「スキル、スキルってよく聞くけど、結局GPTsやGemsと何が違うの」——ここが分かっていないと、Claude Codeの神機能を並べられても「へえ、すごいね」で終わってしまいます。まずはここから整理します。

中身の違いを比較すると

中身指示書＋参考ファイルのみ指示書＋参考ファイルのみ指示書＋実行プログラム＋ファイル構成

  • 実行するかどうかもそのつど生成し直す

Skillのプログラム
  • 処理そのものが固定されている
  • 同じ入力なら同じ出力を返しやすい
  • フォルダ構成で情報も整理できる

この仕組みを使えるのは今のところClaude Code・Codex・Cursor・Antigravityなどコーディングエージェント側が中心。チャットアプリの中で扱えるのは現状ではClaudeがほぼ唯一です。

2

なぜスキルがここまで注目されているのか

理由は大きく3つに整理できます。

1

品質の安定性

プログラムという固定処理があることで、毎回ゼロから生成し直すGPTs方式より結果がブレにくくなります。

2

成果物のサイクルが回る

実行結果がアウトプット用フォルダに溜まり、「良い成果物を参考にしてから始める」と書いておけば、使うほどスキルが育つ好循環が生まれます。

3

専門家の知見の移植

開発が得意な人が作ればSuperpowersのような開発特化スキルに、デザインが得意な人が作ればImpeccableのようなデザイン特化スキルになります。

裏を返すと、今なおGPTsやGemを一生懸命作って配っている状態は、この視点で見るとやや時代遅れです。手軽さという良さは残りますが、繰り返し使う業務・安定した品質が欲しい業務ほど、Skill化する価値は大きくなります。

3

Claude Codeの神機能9選

「知らずに使っていると明らかに損をする」機能を9つ厳選しました。どれも今すぐ試せます。

①

Superpowers

ベテランエンジニアの開発ワークフローを移植するプラグイン。TDDのRED-GREEN-REFACTORサイクルや、要件を固めるブレインストーミングまで組み込めます。

②

スキルの自作

汎用スキルを探すより、自分の業務にぴったり合うスキルを自作する方が価値は大きいという考え方。いつもの作業を言語化してSKILL.mdに落とし込むだけです。

③

Auto Mode

「許可待ち地獄」からの解放。安全な操作はClaudeが自分で判断して進め、リスクがある操作だけ人間に戻す、ちょうどいいバランスの実行モードです。

④

MCP

AIと外部サービスを繋ぐ共通規格。Slack・Notion・Googleカレンダー・Gmailなどを、設定するだけでClaude Codeから操作できるようになります。

⑤

Routines

決まった作業をクラウド上で定期的に自動実行する機能。毎朝決まった時間に業務をこなしてもらえます（デスクトップの「ローカル」表示は実体が別機能）。

⑥

Agent Teams

セキュリティ担当・パフォーマンス担当・テスト担当というように役割ごとのエージェント「チーム」を編成。対等にやり取りしながら分担して進めます。

⑦

Ultra Review

GitHub連携のリモートサンドボックス上で複数のレビューを並列実行するクラウドレビュー。有料の仕組みですが、公開前の最終チェックとして価値があります。

⑧

Remote Control

パソコンでClaude Codeを起動したまま、外出先のスマホから続きの指示を出せる機能。他のツールにも似た仕組みが増えてきていますが、日常的に恩恵を感じやすい使い勝手です。

⑨

デザイン連携

Pencilや、サブスクリプションに含まれるClaude Designと組み合わせると、デザインの質は上がりやすくなります。Pencilは無料で使えます。

多くが研究プレビュー段階の機能を含むため、料金や仕様は変わる可能性があります。まず押さえるなら Superpowers・スキルの自作・MCP の3つです。

4

実際に入れるべきおすすめスキル4選

4つの代表的なスキルと、それぞれの得意分野を紹介します。目的に合わせて選んでみてください。

1

Superpowers

開発系の知見を移植する。ブレインストーミングで要件を固め、計画・実行・レビューする一連の流れを、開発経験がなくても自然になぞれます。

2

Everything Claude Code（ECC）

Claude Code全体の環境を整える。10ヶ月分のベストプラクティス集ですが、中身が多く導入直後は原因の切り分けが難しいため、基本を理解してから使うのがおすすめです。

3

Impeccable

AI感のあるデザインを消す。`/impeccable init`から始まり、`/critique`などのコマンドで既存デザインを磨き上げられます。

4

Find Skills

スキルを探してインストールする。Vercel Labsの`skills.sh`を土台に、`npx skills add`のような形でコマンドラインから直接検索・追加できます。

5

スキルの安全な探し方

良いスキルをどこで見つけるかについては、大きく2つのサイトと、もう1つの探し方があります。

観点Claude Code Marketplaceskills.sh
運営コミュニティ主導の第三者ディレクトリVercelが運営
掲載規模数千件規模のスキル・プラグイン・MCPVercel自身やAnthropic公式、Microsoftなど提供元企業自身の公開が上位に多い
信頼性の見極め誰でも公開できるため玉石混淆どこの誰が作ったか分かりやすい
探し方インストール数・スター順上位表示された実績あるスキルから
もう1つの探し方 — Xでのリアルな評判を検索する

インストール数のような定量的な指標だけでなく、実際にそのスキルを使ったユーザーの生の声を見たいときは、Grokのようにリアルタイムの投稿を検索できるAIで「このスキルを使っている人の感想」を集めるのも有効です。数字だけでは見えない実用感をつかみやすくなります。

共通の見極め方
  • インストール数が多く、公式や有名な企業が出しているものほど安心して使いやすい
  • 聞いたことのない個人名義のスキルは、深く調べずに入れるのは避けたほうが無難
6

今日からの使い方（初心者基準）

「結局何からやればいいの」という人向けに、悩みベースの対応表をまとめます。

  • 何から手をつければいいか分からない開発をしたい→Superpowersを導入し、作りたいものをそのまま伝えてブレインストーミングから始める
  • 毎回同じような許可確認でテンポが悪い→実行モードをAuto Modeに切り替えて、安全な操作は任せてしまう
  • Slack・Notion・Gmailと連携して自動化したい→使っているサービスのMCPを探してインストールし、Claude Codeから操作する
  • 決まった時間に決まった作業を繰り返したい→Routinesで、繰り返している業務を1つ定期実行に登録する
  • 作ったデザインがどこかAIっぽくなってしまう→Impeccableを入れて、`/impeccable init`から始めてみる
  • 良いスキルを探しているけど何が安全か分からない→まずskills.shで公式が出しているものを確認し、気になったらXで評判も検索する
すぐ試せる伝え方
# 難しいコマンドを覚える必要はありません
> 「今、こういうことをやりたい」という悩みをそのまま自然な言葉で伝えるだけで、あとはブレインストーミングのスキルが質問を重ねながら要件を一緒に固めてくれます。
7

もう一歩進んだ使い方

自分でスキルを作る段階に進んだ人向けに、実際のフォルダ構成の考え方を紹介します。

1つのスキルフォルダの構成
  • 1SKILL.md — 中心となる指示書。簡潔に全体の流れだけを書く（目安は200行以内）
  • 2scripts/ — 実際に実行されるプログラム（.pyや.jsなど）
  • 3reference/ — 判断材料になる参考資料やトンマナ
  • 4agents/ — 分析・比較・評価のように、工程ごとに細分化した指示書
  • 5assets/ — 出力結果を確認するビューアーなど、補助的なファイル

指示書をすべてSKILL.mdに詰め込むと長くなりすぎて逆に従いにくくなります。中枢となる流れだけを書き、細かい工程ごとの指示はagents/以下の別ファイルに逃がすと、人にもAIにも分かりやすい構造になります。
